# 🎮 Quiz Game in C Language

## 📖 Overview
The **Quiz Game in C Language** is a lightweight console-based application where users answer questions to test their knowledge. It demonstrates key C programming concepts like input/output handling, loops, and file operations.

## ✨ Features
- 🎲 **Interactive Gameplay**: Answer multiple-choice or open-ended questions.
- 🛠️ **Customizable Questions**: Easily modify questions in the source code.
- 📊 **Score Tracking**: Displays your total score at the end.
- ⚙️ **Error Handling**: Handles invalid inputs smoothly.
- 🚀 **Fast and Lightweight**: Runs efficiently on any system with a C compiler.

## 🚀 How to Run
### Prerequisites
- A C compiler (e.g., GCC or Clang).
- A text editor or IDE (e.g., Visual Studio Code).

### Steps
1. **Clone the Repository**:
    ```bash
    git clone https://github.com/your-username/Quiz-Game-in-C-language.git
    cd Quiz-Game-in-C-language
    ```
2. **Compile the Code**:
    ```bash
    gcc quiz_game.c -o quiz_game
    ```
3. **Run the Program**:
    ```bash
    ./quiz_game
    ```

## 🛠️ Customization
Modify the questions in the source code to create your own quiz. Look for the section where questions are defined and update them as needed.
